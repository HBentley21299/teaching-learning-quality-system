# Leadership dashboard redesign proforma

## Agreed implementation basis — 11 August 2026

- Dashboards adapt to the structured data already captured by the forms. No form fields are added or changed solely to create a KPI.
- Scored form data is shown as a complete five-level distribution, Secure Practice or above percentage, response count and secondary mean. Unscored selections are reported as frequencies and are not presented as scores.
- LIV is reported as a lifecycle using existing data: submitted ELI LIV information is **requested**; an opened LIV case is **case started**; a dated visit is **visit date recorded**; a visit saved as completed is **visited**; and a closed LIV case is **complete**.
- Staff percentages use staff employed during the selected academic year. Record measures use the organisation saved on the record; staff denominators currently use each staff member’s current primary organisation because historical organisation-assignment snapshots are not stored.
- Faculty results are collapsed by default and expand to teams. All configured outcome areas remain available, with search used for long organisation lists and no silent top-eight or top-twelve truncation.
